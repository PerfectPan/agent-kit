Summaries of Claude Code sessions change and `SESSION_SUMMARY_VERSION` is now 2, so caches of `summarizeSession` results recompute. A Claude Code record that opens with a host block and holds the user's text (a system reminder, the IDE's opened file or selection, then the user's words) now counts a turn in `summarizeSession`'s `turns`, collects its prompt and titles the session, where it counted nothing before; a record whose blocks are all host-added text still counts no turn, and one whose own text is only whitespace counts a turn without a prompt. Collected prompts are trimmed for every agent, and a prompt that is only whitespace is no longer collected; one record's prompt joins its text events with a blank line instead of taking the first non-empty one. In `loadTranscript` events of a prompt record, a host-added text block carries `injected: true` in its payload, and session titles and `firstPrompt` of multi-block records are the joined, trimmed text. Consumers that cache prompts, titles or summaries recompute them.
