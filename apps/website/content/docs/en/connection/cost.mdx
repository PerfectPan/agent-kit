## Pricing table

`/cost` prices usage records with a table you pass in, in USD per million tokens. The kit ships no prices. It is pure computation and imports nothing. It runs anywhere.

Exports: `createPricing`, `summarize`, `Pricing`.

```ts title="createPricing and summarize"
import { createPricing, summarize } from "@rivus/agent-kit/cost";
import { createNodePlatform } from "@rivus/agent-kit/node";
import { isUsageRecord, scanUsage, type UsageRecord } from "@rivus/agent-kit/transcript/usage";

const pricing = createPricing(
  { "claude-opus-4-8": { input: 5, output: 25, cacheRead: 0.5, cacheWrite: 6.25, cacheWrite1h: 10 } },
  { fallback: { opus: { input: 15, output: 75, cacheRead: 1.5, cacheWrite: 18.75 } } }
);
const start = new Date();
start.setHours(0, 0, 0, 0);
start.setDate(start.getDate() - 6);
const week = { since: start.getTime(), until: Date.now() };
const records: UsageRecord[] = [];
for await (const item of scanUsage(createNodePlatform(), week)) {
  if (isUsageRecord(item)) {
    records.push(item);
  }
}
const { total, groups } = summarize(records, pricing, { window: week, groupBy: ["agent"] });
```

## How records are priced

`summarize` prices each record using the amount the Agent logged when there is one (Pi, opencode, Grok). Otherwise it prices each count at the model's price (input without cache, cache reads, 5-minute and 1-hour cache writes, output) times the record's `pricingMultiplier` (2 for Codex's priority tier).

A model takes its own id's entry, else the longest key its id contains, regardless of case. `overrides` replace a key's prices, also in part, and `fallback` holds entries such as family aliases.

## Missing prices

A model without a price has no cost (`undefined`, not 0), and a summary's `costUsd` is absent when nothing in it was priced. A Grok turn split by model is priced and grouped per model.

The records come from [Token usage](/docs/connection/token-usage). A record carries `costUsd` and `costSource: "agent"` when the log has the Agent's own cost, and `pricingMultiplier` for Codex's priority tier.
