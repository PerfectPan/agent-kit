---
title: 结果与错误
description: Result 值、产出的读取错误、Effect 标签，以及抛出的 AgentKitError。
---

`@rivus/agent-kit/catalog` 导出 `isBuiltinCodingAgentId`、`Result`、`ok`、`err`、`AgentKitError` 和 `isAgentKitError`。它可以在任何环境运行。`/catalog` 保留 `AgentKitError` 和 `isAgentKitError`，以便调用方识别来自 shell 函数的错误。

- `loadTranscript` 和 `summarizeSession` 解析为 `Result`：`{ ok: true, value }` 或 `{ ok: false, error }`，其中 `error._tag` 标出失败原因。`loadTranscript` 和 `summarizeSession` 的失败为 `SessionNotFound`、`ReadFailed`、`UnknownFormatGeneration`、`NoAdapterAccepted` 或 `CapabilityUnsupported`。
- `detectAgents` 解析为 `Installation[]`。探测失败记在该 Agent 的 `problems` 里。
- `listSessions` 对缺失的根（`RootMissing`）或无法读取的文件（`ReadFailed`）产出 `{ ref, error }`，然后继续下一项。`scanUsage` 以同样方式产出 `{ agent, path, error }`。
- `signal` 选项中止时，调用以 `signal.reason` 拒绝。
- `/acp` 用同类 `_tag` 错误使 Effect 失败：`connectAgent` 产生 `AgentUnavailable` 和 `HandshakeFailed`；打开会话产生 `AuthRequired`、`AcpTimeout`、`AcpRequestFailed`、`ConnectionClosed`、`BindingNotFound`、`LoadUnsupported` 和 `SessionBindingStoreFailure`；回合产生 `TurnInProgress`、`SessionClosed` 和 `CancelUnsettled`。
- 编程错误和缺陷会抛出。在 `listSessions({ agents })` 中指名没有会话适配器的 Agent，或在 `readHookEvent` 中指名没有 hook 方言的 Agent，会抛出 `code: "capability-unsupported"` 的 `AgentKitError`。用 `isAgentKitError` 检测。`summarizeSession` 对不在范围内的非整数 `prompts` 上限同样抛出，`code` 为 `"invalid-prompts"`。`readHookEvent` 不会因为载荷而抛出。

租约失败是带 `_tag` 的类型化值：`LeaseHeld`、`LeaseLost`、`LeaseConfigInvalid`、`LeaseRepositoryFailure`，以及仓储的 `RevisionConflict`。工具包自己不运行 Effect。请在应用的组装根上运行这个程序。

车道失败是带 `_tag` 的类型化值：`LaneQueueFull`、`LanesClosed` 和 `LanesConfigInvalid`。

计划不是由 `planInstall` 返回时，`applyInstall` 以 `code` 为 `"unknown-plan"` 的 `AgentKitError` 终止。遇到 `PlanStale` 或 `TargetChanged` 后要重新计划。`PlanConflict` 对每个冲突给出能够解决它的选项（`"force"`、`"adopt"`、`"backup"`）。
