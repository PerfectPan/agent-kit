---
title: 平台
description: 调用方传入的文件、进程与环境。
---

文件、进程和环境由调用方传入的 `Platform` 提供，因此读取代码也可以在浏览器里运行。

`@rivus/agent-kit/platform` 只导出 `Platform` 类型。任何环境都可以用。

`@rivus/agent-kit/node` 导出 `createNodePlatform`，只在 Node 里运行。读取会话、用量或锁时，从它开始：

```ts title="createNodePlatform"
import { createNodePlatform } from "@rivus/agent-kit/node";

const platform = createNodePlatform();
```

`@rivus/agent-kit-collab` 不绑定具体 Agent。它通过同一个 `Platform` 访问文件、进程、时钟和 SQLite。

除 `/node`、`/node/effect` 与 `/testing` 外，其余入口都可以打包到浏览器中使用。平台的 Effect 包装见 [Effect 入口](/docs/connection/effect)。

OpenCode 的 SQLite 存储需要 `platform.sqlite`。没有它时，用量扫描产出 `SqliteUnavailable`。进程锁在 `platform.sqlite` 存在时使用它，并用 `platform.process.self` 读取持有者身份。细节见 [Token 用量](/docs/connection/token-usage) 和 [进程锁](/docs/coordination/process-locks)。
