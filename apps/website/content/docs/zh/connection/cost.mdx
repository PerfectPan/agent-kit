---
title: 费用
description: 用调用方传入的价格表给用量记录标价。工具包不附带价格。
---

`/cost` 用调用方传入的价格表给用量记录标价，单位是每百万 Token 的美元价格。工具包不附带价格。它是纯计算，不导入任何东西。它可以在任何环境运行。

导出：`createPricing`、`summarize`、`Pricing`。

```ts title="createPricing 与 summarize"
import { createPricing, summarize } from "@rivus/agent-kit/cost";
import { createNodePlatform } from "@rivus/agent-kit/node";
import { isUsageRecord, scanUsage, type UsageRecord } from "@rivus/agent-kit/transcript/usage";

const pricing = createPricing(
  { "claude-opus-4-8": { input: 5, output: 25, cacheRead: 0.5, cacheWrite: 6.25, cacheWrite1h: 10 } },
  { fallback: { opus: { input: 15, output: 75, cacheRead: 1.5, cacheWrite: 18.75 } } }
);
const start = new Date();
start.setHours(0, 0, 0, 0);
start.setDate(start.getDate() - 6);
const week = { since: start.getTime(), until: Date.now() };
const records: UsageRecord[] = [];
for await (const item of scanUsage(createNodePlatform(), week)) {
  if (isUsageRecord(item)) {
    records.push(item);
  }
}
const { total, groups } = summarize(records, pricing, { window: week, groupBy: ["agent"] });
```

有 Agent 记录的金额时，`summarize` 使用该金额（Pi、opencode、Grok）。否则按模型价格给每一项计数标价（不含缓存的输入、缓存读取、5 分钟和 1 小时缓存写入、输出），再乘以记录的 `pricingMultiplier`（Codex 优先层级为 2）。

模型先取自己 id 的条目，否则取它的 id 所包含的最长键，不区分大小写。`overrides` 替换一个键的价格，也可以只替换一部分。`fallback` 存放诸如系列别名这样的条目。

没有价格的模型没有费用（`undefined`，不是 0）。当其中没有任何一项被标价时，汇总的 `costUsd` 缺席。按模型拆开的 Grok 回合按模型标价和分组。

记录来自 [Token 用量](/zh/docs/connection/token-usage)。日志里有 Agent 自己的费用时，记录带 `costUsd` 和 `costSource: "agent"`，并为 Codex 的优先层级带 `pricingMultiplier`。
