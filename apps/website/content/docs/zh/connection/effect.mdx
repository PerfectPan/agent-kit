---
title: Effect 入口
description: PlatformService 与 NodePlatformLive 返回 Effect，工具包自己不运行。
---

Effect 入口返回从 `PlatformService` 读取平台的 Effect 和 Layer。由应用提供 Layer，并自己运行程序。工具包没有 Promise 包装，也不运行 Effect。

`@rivus/agent-kit/platform/effect` 导出 `PlatformService`，也就是作为 Effect 服务的 `Platform`。任何环境都可以用，需要 `effect`。

`@rivus/agent-kit/node/effect` 导出 `NodePlatformLive`。它是用 `createNodePlatform()` 提供 `PlatformService` 的 Layer，只在 Node 里运行，需要 `effect`。

```ts title="PlatformService"
import * as Effect from "effect/Effect";

import { NodePlatformLive } from "@rivus/agent-kit/node/effect";
import { PlatformService } from "@rivus/agent-kit/platform/effect";

const program = Effect.gen(function* () {
  const platform = yield* PlatformService;
  return platform.home;
});
const exit = await Effect.runPromiseExit(program.pipe(Effect.provide(NodePlatformLive)));
```

换一份 `env` 或 `home` 时，改为提供 `Layer.succeed(PlatformService, createNodePlatform({ env, home }))`。

`effect` 必须与 `peerDependencies.effect` 完全一致。见 [安装](/docs/installation)。普通入口不会加载上述可选 peer。

其他 Effect 入口是 [Harness 安装](/docs/connection/harness)、[ACP](/docs/connection/acp)、[租约](/docs/coordination/leases) 和 [车道](/docs/coordination/lanes)。
