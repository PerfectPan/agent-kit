## @rivus/agent-kit

```bash title="安装 @rivus/agent-kit"
npm install @rivus/agent-kit
```

安装要求：仅支持 ESM，没有副作用，需要 Node.js 22.13 及以上。

除 `/node`、`/node/effect` 与 `/testing` 外，其余入口都可以打包到浏览器中使用。

Effect 入口要求宿主安装的 `effect` 与 `peerDependencies.effect` 完全一致。用下面的命令查看版本：

```bash title="读取 effect peer"
npm view @rivus/agent-kit peerDependencies.effect
```

普通入口不会加载上述可选 peer。[简介](/docs) 入口表的**运行环境**一列用「需要 `effect`」标出这些入口。

## @rivus/agent-kit-collab

```bash title="安装两个包和 effect peer"
npm install @rivus/agent-kit @rivus/agent-kit-collab
# Read the exact effect peer version for /lease and /lanes, then install that version:
npm view @rivus/agent-kit-collab peerDependencies.effect
npm install --save-exact "effect@$(npm view @rivus/agent-kit-collab peerDependencies.effect)"
```

两个包使用同一版本。这些文档跟随 main 分支。npm 上的版本会落后，直到下一次发布。每个包的 CHANGELOG 列出已经发布的内容。

安装更早的版本时，查询 `npm view @rivus/agent-kit-collab@<version> peerDependencies.effect`，并在安装命令的查询里使用同一个 `@<version>` 后缀。

`@rivus/agent-kit` 是 peer。进程里因此只有一份平台类型。`/lease` 和 `/lanes` 要求宿主安装的 `effect` 与 `peerDependencies.effect` 完全一致，以上面那条命令的输出为准。普通入口不需要上述可选 peer。

仅支持 ESM，没有副作用。在 darwin 或 linux 上需要 Node.js 22.13 及以上。

不支持 win32。平台在 win32 上无法识别进程（boot id、pid、启动时间），而 lease 和锁文件需要这些信息。SQLite 进程锁仍然可以取得，此时 `holder` 为 `undefined`。详见 [进程锁](/docs/coordination/process-locks)。

每种锁都只支持本地目录。SQLite 的锁和锁文件在 NFS 上都不可靠。

持有者按主机名、boot id、pid 和启动时间判断。共用一把锁的进程必须看到同一张进程表。容器如果共用主机名和内核，但不共用 PID 命名空间，则不受支持。持有锁期间主机被改名，持有者会被看成远程持有者，只按 TTL 判断。已死持有者的锁文件会一直留到被删除。

状态是 0.x。本包与 `@rivus/agent-kit` 锁定步进发布，版本号相同。次版本可能包含破坏性变更。
