description: 仅 ESM，Node.js 22.13 或更高版本，effect 这个 peer，以及两个包的同一版本。
---

## @rivus/agent-kit

```bash title="安装 @rivus/agent-kit"
npm install @rivus/agent-kit
```

仅 ESM，没有副作用，需要 Node.js 22.13 或更高版本。

除 `/node`、`/node/effect` 和 `/testing` 以外，每个入口也会打成浏览器包。

Effect 入口要求宿主把 `effect` 安装成与 `peerDependencies.effect` 完全相同的版本。用下面的命令读取：

```bash title="读取 effect peer"
npm view @rivus/agent-kit peerDependencies.effect
```

普通入口不会加载这个可选 peer。[简介](/zh/docs) 入口表的**运行环境**一列用「需要 `effect`」标出依赖它的入口。

入口表描述的是源码 API。采用前请核对所选 npm 版本的导出。迁移检查和回滚见 [采用 agent-kit](https://github.com/PerfectPan/agent-kit/blob/main/docs/development/adoption.md)。

## @rivus/agent-kit-collab

```bash title="安装两个包和 effect peer"
npm install @rivus/agent-kit @rivus/agent-kit-collab
# Read the exact effect peer version for /lease and /lanes, then install that version:
npm view @rivus/agent-kit-collab peerDependencies.effect
npm install --save-exact "effect@$(npm view @rivus/agent-kit-collab peerDependencies.effect)"
```

选择已核对、非占位、且导出所需入口的发布版本。两个包使用同一版本。迁移检查和回滚见 [采用 agent-kit](https://github.com/PerfectPan/agent-kit/blob/main/docs/development/adoption.md)。

已核对的旧版本请查询 `npm view @rivus/agent-kit-collab@<version> peerDependencies.effect`，并在安装命令的查询里使用同一个 `@<version>` 后缀。

`@rivus/agent-kit` 是 peer 依赖，因此进程里只有一份平台类型。Effect 入口 `/lease` 和 `/lanes` 要求宿主把 `effect` 安装成与 `peerDependencies.effect` 完全相同的版本，以上面那条命令的输出为准。普通入口不需要这个可选 peer。

仅 ESM，没有副作用，在 darwin 或 linux 上需要 Node.js 22.13 或更高版本。

不支持 win32：平台在那里无法识别进程（boot id、pid 和启动时间），而租约和锁文件需要这些信息。SQLite 进程锁仍然可以取得，此时 `holder` 为 `undefined`，详见 [进程锁](/zh/docs/coordination/process-locks)。

每种锁都只支持本地目录。SQLite 的锁和锁文件在 NFS 上都不可靠。

持有者按主机名、boot id、pid 和启动时间判断，因此共用一把锁的进程必须看到同一张进程表。共用主机名和内核、但不共用其 PID 命名空间的容器不受支持。持有锁期间主机被改名，会让它的持有者看起来像远程持有者（只按 TTL 判断；已死持有者的锁文件会一直留到被删除）。

状态为 0.x。本包与 `@rivus/agent-kit` 共用一套锁定步进发布策略（同一版本）。次版本可能包含破坏性变更。
