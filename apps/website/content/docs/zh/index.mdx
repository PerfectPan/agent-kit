`@rivus/agent-kit` 一次连接一个 Agent。它为对接 Claude Code、Codex、Grok 这类第三方编码 Agent 的应用提供基础模块。工具包知道每个 Agent 的 id 和主目录，列出它的会话，并把日志读成同一种 transcript 模型、同一种用量约定。

`@rivus/agent-kit-collab` 协调多个 Agent。它增加围栏租约（`/lease`）、单实例进程锁（`/process-lock`）和按键调度的车道（`/lanes`）。这个包不认识任何具体 Agent。Collab 的入口使用 agent-kit 的公开平台，并遵循同一套锁定步进发布。

文件、进程和环境来自调用方传入的 `Platform` 对象，因此读取代码也能在浏览器里运行。ACP 实现在 `/acp`。`/harness` 把应用的 hook 和 skill 装进这些 Agent，也可以再卸掉，并用账本记录它写过的内容。

状态为 0.x。次版本可能包含破坏性变更。两个包共用一套锁定步进发布策略，因此发出同一版本。

## 入口

源码 API 在 `@rivus/agent-kit` 中有 17 个入口，在 `@rivus/agent-kit-collab` 中有 3 个（合计 20 个）。下表描述的是这份源码 API。采用前请核对所选 npm 发布版本确实导出了需要的入口。参见 [采用 agent-kit](https://github.com/PerfectPan/agent-kit/blob/main/docs/development/adoption.md)。

| [`@rivus/agent-kit/providers`](/zh/docs/concepts/providers)            | `Provider`、`builtinProviders`                                                                              | 任何环境                              |

| ----------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- | ------- |
| [`@rivus/agent-kit-collab/process-lock`](/zh/docs/coordination/process-locks) | `acquireProcessLock`、`isProcessLockHeld`、`ProcessLock`、`ProcessLockPlatform`                                  | 普通 TS |

| [`@rivus/agent-kit-collab/lanes`](/zh/docs/coordination/lanes)                | `createLanes`                                                                                                    | Effect  |

`/providers` 的 `builtinProviders` 在支持时暴露每个 Agent 的 `identity`、`discovery`、`install`、`sessions`、`usage` 和 `acp` 服务。按 `id` 选出描述符，使用前再检查可选服务是否存在。普通入口共用这些服务对象。Hook 命令继续使用 `/harness/events` 的 `builtinHookDialects`。那份隔离构建不导入任何东西，并持有单独的 hook 对象。`/catalog` 保留 `AgentKitError` 和 `isAgentKitError`，以便调用方识别来自 shell 函数的错误。

**运行环境**一列用「需要 `effect`」标出依赖 `effect` 的入口。普通入口不会加载这个可选 peer。

## 仓库

本项目是 pnpm workspace 单仓，布局与 [PerfectPan/project-template-pnpm](https://github.com/PerfectPan/project-template-pnpm) 相同。每个限界上下文是 `packages/` 下的私有包。`packages/agent-kit` 是发布外壳，重新导出它们的公开名称，并打包进 `dist`。`infra/architecture/boundaries.ts` 声明哪个包、哪一层可以导入什么，`vp lint` 据此检查每个包的导入。

```bash
pnpm install
pnpm run check   # format, build, lint, typecheck, test, package checks
```
