# DeepSeek Harness provider

Private implementation of DeepSeek Harness identity, discovery, sessions and ACP, bundled into `@rivus/agent-kit`. `facts.ts` owns the home rule and format generation, `layout.ts` owns the session directory layout, and `sessions/` translates the event log. `zstd.ts` reads the concatenated Zstandard frames the harness writes by default. `discovery.ts` probes the `dsh` command and the home, and counts the YAML `.credentials.yaml` as a login by its existence alone. `acp.ts` launches `dsh --profile acp`, which serves ACP v1 without authentication and has no `_meta` channel; `session/new` succeeds without a stored key, so `probeAgent` reports the harness ready before a login. `dsh-acp` joins adjacent text blocks without a separator, so the first-block system prompt runs straight into the first user text. Tests run the shared discovery and session conformance suites, the latter on plain logs, and a separate case on compressed logs. The harness has no command hooks, only in-process Cordis plugins, so there is no hook dialect or installer; there is no usage decoder yet.
