# Cursor provider

Private implementation of Cursor identity, discovery, hooks, installation and ACP, bundled into `@rivus/agent-kit`. Each service has its own export; `facts.ts` owns its paths, commands and host markers. `acp.ts` targets `cursor-agent acp` (using `cursor-agent` rather than `agent` to avoid colliding with unrelated `agent` binaries on `PATH`). Context imports use SPI entries. Tests run hook and discovery conformance; cross-agent host-sniffing tests stay in testing and harness. Cursor has no verified identity home rule, session adapter or usage decoder (modern Cursor tracks token usage server-side rather than writing non-zero counts into local `state.vscdb` bubbles).
